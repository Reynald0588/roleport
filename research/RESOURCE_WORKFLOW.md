# Roleport 求职资源标准化执行流程

## 目标

以低维护成本持续补充真实、可用、对求职者有明确价值的资源。候选资源必须经过机器初筛和人工审核后，才能进入 `resources.js`。

## 状态流转

```text
候选发现
→ 官方链接核实
→ 机器初筛
→ 待人工审核
→ 审核通过 / 退回补充 / 排除
→ 写入 resources.js
→ 定期复查
```

## 1. 候选发现

来源优先级：

1. 平台官方网站和官方帮助页。
2. 搜索引擎结果，用于发现候选，不作为官方链接的最终依据。
3. 求职者社区中的高频提及。
4. 同类可信资源导航中的交叉验证。

禁止直接把来源不明的聚合站、论坛转帖或下载站写入正式资源。

## 2. 官方链接核实

每条候选必须确认：

- 域名与平台名称一致。
- 首页可通过 HTTPS 打开。
- 页面标题或站点介绍能说明平台用途。
- 不是域名停放页、出售页、仿冒站或无内容壳站。
- 不是要求先付费才能查看正常岗位的误导页面。
- 官网链接不是搜索结果跳转地址。

## 3. 机器初筛

总分 100 分：

| 维度 | 分值 | 判断重点 |
|---|---:|---|
| 品牌与可信度 | 20 | 平台是否知名、主体是否清晰、是否存在大量投诉 |
| 岗位丰富度 | 20 | 是否有足够岗位、更新是否活跃、是否覆盖目标岗位 |
| 使用便利性 | 15 | 搜索、筛选、岗位详情和申请入口是否清楚 |
| 中文友好度 | 15 | 是否提供中文界面、中文岗位或适合中文用户 |
| 差异化价值 | 10 | 是否补充现有资源的空白 |
| 链接稳定性 | 10 | HTTPS、可访问性、重定向和页面稳定性 |
| 风险与透明度 | 10 | 收费、隐私、虚假岗位和诱导行为风险 |

处理规则：

- 80–100：优先人工审核
- 70–79：备选，人工确认是否值得加入
- 60–69：谨慎，除非有明显差异化价值
- 低于 60：不进入人工审核

## 4. 硬性排除条件

出现任一项直接排除：

- 钓鱼、仿冒、恶意下载或明显诈骗风险。
- 岗位信息长期不更新或几乎为空。
- 主要业务不是招聘、求职、兼职或职业服务。
- 必须付费才能查看正常岗位或申请。
- 域名停放、出售、失效或无法确认官方身份。
- 与已有资源高度重复，且没有明显优势。
- 需要安装不明软件或提交过度敏感信息。

## 5. 人工审核

审核人逐项确认：

- [ ] 官网可正常打开
- [ ] 平台身份可信
- [ ] 有真实、持续更新的岗位或职业服务
- [ ] 中文用户能够正常使用
- [ ] 岗位搜索和详情页面可用
- [ ] 收费与隐私规则可以理解
- [ ] 与现有资源相比有加入价值
- [ ] 名称、分类、介绍和标签准确
- [ ] 官方链接没有错误跳转

审核结果填写在 `manual_status`，正式入库时在 `site_status` 记录“已入库 / 未入库 / 技术暂缓”。

审核结果只能是：

- `审核通过`：可以写入正式资源
- `需修改`：名称、链接或介绍需要修改
- `不加入`：不加入

## 分类规则

分类采用“主分类 + 辅助分类”：

- 主分类表示平台的核心产品形态，用于资源卡片的第一个标签。
- 辅助分类表示平台同时具备的内容或工作方式，可选。
- 分类筛选会同时匹配主分类和辅助分类，因此筛选结果允许重叠。

示例：

- 电鸭社区：主分类“求职社群与内推”，辅助分类“远程工作平台”。
- DeJob：主分类“Web3 招聘”，辅助分类“远程工作平台”。
- 牛客网：主分类“互联网与科技招聘”，辅助分类“求职社群与内推”。

## 6. 正式入库

审核通过后，把资源复制到 `resources.js`。

正式资源至少包含：

```text
id
name
domain
url
category
language
region
letter
tone
desc.zh
desc.en
```

字段规则：

- `language`：`zh`、`en`、`bilingual`
- `region`：`cn`、`global`、`remote`
- `category`：`general`、`tech`、`web3`、`remote`、`freelance`、`community`、`resume`、`learning`

## 7. 自动校验

每次修改后打开：

```text
http://localhost:8000/tests/resource-directory-test.html
```

必须确认：

- 资源 ID 唯一
- URL 为 HTTPS
- 分类、语言、地区合法
- 中文和英文介绍均存在
- 没有重复链接
- 页面仍可正常渲染

## 8. 定期复查

建议每月一次，至少每季度一次：

- 抽查官网是否还能打开。
- 检查重要平台是否已停止运营或更改域名。
- 删除长期无岗位、严重商业化或存在明显风险的资源。
- 更新失效链接和介绍。

自动访问检查只能作为辅助，不能替代人工查看岗位真实性和使用体验。
